## 🚀 Usage Examples

### Create an MCP with RAG Guidance
```bash
curl -X POST http://localhost:4000/api/create-mcp \
  -H "Content-Type: application/json" \
  -d '{
    "name": "intelligent-file-manager",
    "description": "AI-powered file operations with smart organization",
    "template": "file-system",
    "complexity": "advanced"
  }'
```

### Get RAG-Powered Guidance
```bash
curl -X POST http://localhost:4000/api/rag/guidance \
  -H "Content-Type: application/json" \
  -d '{
    "query": "I need help optimizing database performance",
    "context": {"template": "database", "complexity": "expert"}
  }'
```

### Access Web Interfaces
- **MCP Builder**: http://localhost:4000
- **Sherlock IDE**: http://localhost:3000  
- **ReliaKit Dashboard**: http://localhost:5000
- **Chi Flow Platform**: http://localhost:3002
