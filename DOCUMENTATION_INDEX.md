## 🔍 Quick Reference

### Key Commands
```bash
# Launch Spec Kit
.\launch.ps1

# Initialize new project
.\launch.ps1 init my-project --ai copilot

# Check installed tools
.\launch.ps1 check

# Get help
specify --help
```

### Slash Commands (In Your AI Agent)
```
/constitution  - Define project principles
/specify       - Describe what to build
/clarify       - Clarify requirements
/plan          - Create technical plan
/tasks         - Break down into tasks
/analyze       - Analyze consistency
/implement     - Build the feature
```

### Supported AI Agents
- GitHub Copilot (`--ai copilot`)
- Claude Code (`--ai claude`)
- Cursor (`--ai cursor`)
- Gemini CLI (`--ai gemini`)
- And 8 more...
